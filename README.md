# Job Tracker

A full-stack application for organising job applications and tracking the recruitment process.

The application source code is in [`job-application-tracker/`](./job-application-tracker/).

## Technology

- **Frontend:** React, TypeScript, Vite
- **Backend:** Java 21, Spring Boot 3.5.5, Spring Security, JWT
- **Database:** PostgreSQL 16
- **API documentation:** Springdoc OpenAPI / Swagger
- **Local environment:** Docker Compose

## Current functionality

- Account registration and sign-in
- JWT-protected application endpoints
- Create, view, edit and delete job applications
- Track application status
- Search and filter applications
- Dashboard counts by status
- Responsive interface

See the [project README](./job-application-tracker/README.md) for setup instructions and API details.

> This project is under active development. Run it locally and verify the features before relying on it for real application records.
